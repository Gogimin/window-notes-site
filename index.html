Window Notes Uploader

YouTube 채널 Window Notes(창가 기록) 운영자가 자기 채널에 영상을 올리기 위해 쓰는 내부 도구입니다.
An internal tool used only by the owner of the YouTube channel Window Notes to upload videos to that channel.

개인정보처리방침 / Privacy Policy이용약관 / Terms

무엇을 하나요 / What it does

  • 채널 운영자가 자기 PC에서 만든 음악 영상(롱폼·쇼츠)을 YouTube API 서비스(YouTube API Services)로 자기 채널에 비공개로 올립니다.
  • 제목·설명·태그·챕터·썸네일과 AI 제작 표시(합성 콘텐츠)를 함께 설정하고, 운영자가 고친 글을 이미 올린 영상에 반영합니다.
  • 공개 전환은 운영자가 직접 확인·승인한 뒤에만 합니다.
  • Uploads the channel owner's own music videos as private videos via the YouTube API Services, sets titles, descriptions, tags, chapters, thumbnails and the altered/synthetic content disclosure, and updates that metadata later. Publishing happens only after the owner's review.

누가 쓰나요 / Who uses it

채널 운영자 한 사람만 씁니다. 외부 사용자 가입·로그인 기능이 없고, 다른 사람의 YouTube 계정이나 데이터에 접근하지 않습니다.
Only the channel owner uses it. There is no public sign-up, and it never accesses other people's YouTube accounts or data.

어디서 실행되나요 / Where it runs

운영자의 Windows PC에서 실행되는 데스크톱 도구입니다. 별도의 서버가 없고, 로그인 정보는 그 PC에만 저장됩니다.
A desktop tool that runs on the owner's Windows PC. There is no server; sign-in tokens are stored only on that PC.
